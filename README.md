# Automation Pause and Resume

Pause any Home Assistant automation for a set time. It turns on again by itself.

Status: in development. The build plan is in [docs/PLAN.md](docs/PLAN.md).

## Planned features

- Pause any automation for 15 minutes, 1 hour, 1 day, 1 week or a custom time.
- No helper, script or edit per automation. New automations appear without a change.
- The pause survives a Home Assistant restart.
- A dashboard that looks like Settings → Automations, with search and sort by last triggered.

## Install

Not released yet. The release will install through HACS as a custom repository.
